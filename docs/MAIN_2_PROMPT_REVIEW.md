# Main_2 prompt review

Reviewed the scene's authored speech, calibration prompts, wrist labels, lesson cues, and Free Play and audio-only transitions on 2026-11-15. The table records the original review. The updated device checklist lists the current controls.

The proposed count-in wording, “Press any key to start the count-in,” is a possible follow-up. The current countdown, start cue, and performance feedback stay in use. The optional blue-guide alignment instruction was dropped. Fingering starts off on every app launch and uses a disabled button outside Lesson.

| --- | --- | --- |
| Welcome | The introduction commits to Für Elise and asks a yes/no question before the player chooses a mode. Any reply or silence continues setup. | “I’m your piano coach. First, let’s set up your keyboard.” If voice input is available, add “Say ‘audio only’ to skip visual setup.” Leave the song choice for after setup. |
| Permissions | Android can request microphone access before the intro and scene access during calibration. | Marker retry or fallback | Invalid spacing reports a measurement. Tracking failure can put a technical reason in the prompt. | Spacing retry: “Check that the markers are behind the two end keys. Name the key and edge on every retry, for example “Pinch the back edge of the far-left key, where it meets the piano panel.” Use “front edge closest to you” for the other end. |

| Lesson demonstration | The sheet and key cues can appear during a demonstration. The upcoming sheet header identifies the section, but a first-time player can mistake the demo for their turn. | Use “Watch the demo” during playback and “Your turn” at the handoff.
