# Coach Playbook — how a lesson progresses

The rules that decide what the student plays next: which measures, with which hand, at what tempo, and when to go back
and fix something. A lesson builds a piece up one measure at a time (right hand, left hand, then both), checks it with
full play-throughs, and repairs weak spots before moving on.

## Definitions

- **Run:** one play-through of a set of measures, with one hand or both, at a set tempo.
- **Hand:** right hand alone, left hand alone, or both hands together. In a one-hand run only that hand's notes are
  expected; keys of the other hand count as wrong notes.
- **Stage:** one of the three hand settings a new measure is learned in: right hand, left hand, both hands.
- **Tempo ladder:** 50% → 75% → 100% of the song's tempo. "Slow" is the bottom step; "song tempo" is 100%.
- **Measure rating**, given to every measure after each run:

| Rating | Meaning |
|---|---|
| Clean | Every note right on the first try, no long pause |
| Shaky | One wrong note, or one long pause (over 1.5 s) |
| Problem | Two or more wrong notes |

- **Rating per hand:** in a both-hands run every measure is rated once for each hand. The measure's rating is the worse
  of the two, and a hand rated Problem (or Shaky) is that measure's **weak hand**.
- **Tempo rating**, given to every run by comparing the speed actually played with the speed asked for:

| Rating | Meaning | Coach says |
|---|---|---|
| On tempo | Within 15% of the asked tempo | nothing, or praise |
| Too slow | More than 15% slower | "a little faster" |
| Too fast | More than 15% faster | "slow down" |

- **Rushed / dragged measures:** the same check per measure, so the coach can say where the speed drifted.
- **Passed run:** no Problem measures, at least 90% of notes right on the first try, and On tempo.
- **Exception:** below song tempo, a run that is Too fast but otherwise passes still counts as passed (the student is ahead of
  the step). At song tempo, Too fast fails.
- **Nothing to play:** a hand with no notes in the measures of a run is skipped. If only one hand has notes there,
  the both-hands run is skipped too, because it would be the same as the one-hand run.

## Step 1: Learn the new measure

1. Learn the new measure N in three stages, in this order: right hand alone, left hand alone, both hands together.
2. Each stage starts at slow tempo.
3. After a passed run, go up one tempo step and play the same stage again.
4. After a passed run at song tempo, go to the next stage. After the last stage, go to Step 2.
   For measure 1 there is nothing to join, so skip to Step 4.
5. Skip a stage that has nothing to play (see "Nothing to play").
6. After a failed run, repeat the same stage at the same tempo. The coach names the one thing to fix: a note
   (and which hand), or faster/slower.
7. After 3 failed runs in a row at the same tempo, go down one step in the same stage. If already at slow, the coach
   gives help (a demo or the fingering) and the student tries again.

## Step 2: Full play-through

8. Play measures 1 through N, both hands together, at song tempo.
9. Rate every measure for each hand, and rate the tempo.
10. If the run passed, go to Step 4.
11. If any measure is rated Problem, go to Step 3.
12. If the run failed with no Problem measure (thinly spread errors, or off tempo), repeat the play-through.
    After 2 such failures in a row, treat the Shaky measures as problem blocks and go to Step 3.

## Step 3: Repair problem blocks

13. Group the Problem measures into blocks. Neighbours form one block (4, 5, 6 → block 4–6).
    Separate ones stay separate (1, 6, 8 → three blocks).
14. Work through the blocks in order, earliest first.
15. Choose the lead-in for each block from the (up to) two measures before it:
    - If either is Shaky, include them, so the student practises the approach.
    - If they are Clean, or the block starts at measure 1, play the block alone.
16. Repair each weak hand of the block on its own, right hand first: play the block (with any lead-in) with that hand
    alone at slow tempo. After a passed run, go to song tempo. After a passed run at song tempo, that hand is fixed.
    A hand that was Clean throughout the block is not repaired.
17. Then play the block (with any lead-in) both hands together at song tempo. After a passed run, the block is fixed.
18. Only the block's own measures decide pass or fail. Lead-in measures are not judged.
19. No repairs inside repairs. If a run of rule 16 or 17 keeps failing, rule 7 applies; after stepping down to slow,
    a passed run goes back to song tempo.
20. When all blocks are fixed, go back to Step 2 and play the full range again.

## Step 4: Advance

21. Add the next measure (N + 1) and go to Step 1.
22. If N was the last measure, the piece is complete.

## Example lesson

A student starts a new piece in which both hands play in every measure. Each row is one run; the last column says
which rule decides what happens next.

| Run | Student plays | Hand | Tempo | What happened | Result and next step |
|---|---|---|---|---|---|
| 1 | Measure 1 | Right | 50% | All notes right, on tempo | Passed. Go up a step (rule 3) |
| 2 | Measure 1 | Right | 75% | One wrong note (Shaky, under 90%) | Failed. Repeat; coach names the note (rule 6) |
| 3 | Measure 1 | Right | 75% | All notes right, on tempo | Passed. Go up a step (rule 3) |
| 4 | Measure 1 | Right | 100% | All notes right, on tempo | Passed. Next stage: left hand, back at slow (rules 2, 4) |
| 5 | Measure 1 | Left | 50% | All notes right, but Too fast | Passed by the exception: ahead of the step. Go up (rule 3) |
| 6 | Measure 1 | Left | 75% | All notes right, on tempo | Passed. Go up a step (rule 3) |
| 7 | Measure 1 | Left | 100% | All notes right, but Too slow | Failed. Repeat; coach asks for "a little faster" (rule 6) |
| 8 | Measure 1 | Left | 100% | All notes right, on tempo | Passed. Next stage: both hands, back at slow (rules 2, 4) |
| 9 | Measure 1 | Both | 50% | All notes right, on tempo | Passed. Go up a step (rule 3) |
| 10 | Measure 1 | Both | 75% | All notes right, on tempo | Passed. Go up a step (rule 3) |
| 11 | Measure 1 | Both | 100% | All notes right, on tempo | Passed. Measure 1 has no play-through; add measure 2 (rules 4, 21) |
| 12–20 | Measure 2 | Right, Left, Both | 50%, 75%, 100% each | All passed | Last stage passed at song tempo. Go to the full play-through (rule 4) |
| 21 | Measures 1–2 | Both | 100% | All Clean in both hands, on tempo | Passed. Add measure 3 (rules 10, 21) |
| … | Measures 3, 4, 5 and 6 are each learned the same way: right, left, both, then a play-through from measure 1 | | | | |
| 70 | Measures 1–6 | Both | 100% | Measure 2: left hand Problem. Measure 4: Shaky. Measure 5: both hands Problem. The rest Clean | Failed with Problem measures. Repair two blocks: 2 and 5 (rules 11, 13) |
| 71 | Measure 2 | Left | 50% | All notes right, on tempo | Passed. Left hand only, because the right hand was Clean; no lead-in because measure 1 was Clean (rules 15, 16) |
| 72 | Measure 2 | Left | 100% | All notes right, on tempo | Passed. The left hand is fixed; now both hands (rules 16, 17) |
| 73 | Measure 2 | Both | 100% | All Clean, on tempo | Passed. Block 2 is fixed; move to block 5 (rules 14, 17) |
| 74 | Measures 3–5 | Right | 50% | One wrong note in measure 4, measure 5 Clean | Passed. Measures 3–4 are the lead-in because measure 4 was Shaky, and lead-ins are not judged (rules 15, 18) |
| 75 | Measures 3–5 | Right | 100% | Measure 5 Clean, on tempo | Passed. The right hand is fixed; now the left (rule 16) |
| 76 | Measures 3–5 | Left | 50% | Measure 5 Clean, on tempo | Passed. Go to song tempo (rule 16) |
| 77 | Measures 3–5 | Left | 100% | Two wrong notes in measure 5 | Failed. Repeat at the same tempo (rule 6) |
| 78 | Measures 3–5 | Left | 100% | Measure 5 Clean, on tempo | Passed. The left hand is fixed; now both hands (rules 16, 17) |
| 79 | Measures 3–5 | Both | 100% | Measure 5 Clean in both hands, on tempo | Passed. All blocks fixed; play the full range again (rules 17, 20) |
| 80 | Measures 1–6 | Both | 100% | All Clean, on tempo | Passed. Add measure 7 (rules 10, 21) |

Cases the table doesn't reach:

- **A hand has nothing to play:** if the left hand rests for all of measure 3, measure 3 is learned with the right hand
  only: no left-hand stage and no both-hands stage (rule 5). The play-through still follows.
- **Stuck at a tempo:** if run 77 had failed three times in a row, the left hand would drop back to 50% (rules 7, 19).
- **Never quite clean:** if a play-through fails twice with only Shaky measures, those Shaky measures are repaired as if
  they were Problem blocks, and the hands rated Shaky are the weak hands (rule 12).

## Numbers that can be tuned

| Setting | Value |
|---|---|
| Stage order | right hand, left hand, both hands |
| Tempo ladder | 50%, 75%, 100% |
| Long pause | over 1.5 s |
| Problem measure | 2 or more wrong notes |
| Pass mark | 90% of notes right on the first try |
| On tempo | within 15% of the asked tempo |
| Failed runs before stepping down a tempo | 3 |
| Failed play-throughs before repairing Shaky measures | 2 |
| Lead-in length | up to 2 measures |

## Who applies the rules

The lesson code applies this playbook, and the AI coach explains each step to the student
("measure 5 tripped up your left hand, let's take it slowly with the two bars before it") and chooses the help in rule 7.
Every rule is a threshold check, so code applies it the same way every time and the lesson keeps moving if the AI is slow or offline.
