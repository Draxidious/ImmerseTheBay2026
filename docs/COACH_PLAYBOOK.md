# Coach Playbook — how a lesson progresses

The rules that decide what the student plays next: which measures, at what tempo, and when to go back and fix something.
A lesson builds a piece up one measure at a time, checks it with full play-throughs, and repairs weak spots before moving on.

## Definitions

- **Run:** one play-through of a set of measures at a set tempo.
- **Tempo ladder:** 50% → 75% → 100% of the song's tempo. "Slow" is the bottom step; "song tempo" is 100%.
- **Measure rating**, given to every measure after each run:

| Rating | Meaning |
|---|---|
| Clean | Every note right on the first try, no long pause |
| Shaky | One wrong note, or one long pause (over 1.5 s) |
| Problem | Two or more wrong notes |

- **Tempo rating**, given to every run by comparing the speed actually played with the speed asked for:

| Rating | Meaning | Coach says |
|---|---|---|
| On tempo | Within 15% of the asked tempo | nothing, or praise |
| Too slow | More than 15% slower | "a little faster" |
| Too fast | More than 15% faster | "slow down" |

- **Rushed / dragged measures:** the same check per measure, so the coach can say where the speed drifted.
- **Passed run:** no Problem measures, at least 90% of notes right on the first try, and On tempo.
- **Exception:** below song tempo, a run that is Too fast but otherwise passes still counts as passed (the student is ahead of
  the step). At song tempo, Too fast fails.

## Step 1: Learn the new measure

1. Play the new measure N alone at slow tempo.
2. After a passed run, go up one tempo step and play it again.
3. After a passed run at song tempo, go to Step 2. For measure 1 there is nothing to join, so skip to Step 4.
4. After a failed run, repeat at the same tempo. The coach names the one thing to fix: a note, or faster/slower.
5. After 3 failed runs in a row at the same tempo, go down one step. If already at slow, the coach gives help
   (a demo or the fingering) and the student tries again.

## Step 2: Full play-through

6. Play measures 1 through N at song tempo.
7. Rate every measure and the tempo.
8. If the run passed, go to Step 4.
9. If any measure is rated Problem, go to Step 3.
10. If the run failed with no Problem measure (thinly spread errors, or off tempo), repeat the play-through.
    After 2 such failures in a row, treat the Shaky measures as problem blocks and go to Step 3.

## Step 3: Repair problem blocks

11. Group the Problem measures into blocks. Neighbours form one block (4, 5, 6 → block 4–6).
    Separate ones stay separate (1, 6, 8 → three blocks).
12. Work through the blocks in order, earliest first.
13. Choose the lead-in for each block from the (up to) two measures before it:
    - If either is Shaky, include them, so the student practises the approach.
    - If they are Clean, or the block starts at measure 1, play the block alone.
14. Play the block (with any lead-in) at slow tempo. After a passed run, go to song tempo.
    After a passed run at song tempo, the block is fixed.
15. Only the block's own measures decide pass or fail. Lead-in measures are not judged.
16. No repairs inside repairs. If a block keeps failing, rule 5 applies.
17. When all blocks are fixed, go back to Step 2 and play the full range again.

## Step 4: Advance

18. Add the next measure (N + 1) and go to Step 1.
19. If N was the last measure, the piece is complete.

## Example lesson

A student starts a new piece. Each row is one run; the last column says which rule decides what happens next.

| Run | Student plays | Tempo | What happened | Result and next step |
|---|---|---|---|---|
| 1 | Measure 1 | 50% | All notes right, on tempo | Passed. Go up a step (rule 2) |
| 2 | Measure 1 | 75% | One wrong note (Shaky, under 90%) | Failed. Repeat; coach names the note (rule 4) |
| 3 | Measure 1 | 75% | All notes right, on tempo | Passed. Go up a step (rule 2) |
| 4 | Measure 1 | 100% | All notes right, but Too slow | Failed. Repeat; coach asks for "a little faster" (rule 4) |
| 5 | Measure 1 | 100% | All notes right, on tempo | Passed. Measure 1 has no play-through; add measure 2 (rules 3, 18) |
| 6 | Measure 2 | 50% | All notes right, but Too fast | Passed by the exception: ahead of the step. Go up (rule 2) |
| 7 | Measure 2 | 75% | All notes right, on tempo | Passed. Go up a step (rule 2) |
| 8 | Measure 2 | 100% | All notes right, on tempo | Passed. Go to the full play-through (rule 3) |
| 9 | Measures 1–2 | 100% | All Clean, on tempo | Passed. Add measure 3 (rules 8, 18) |
| … | Measures 3, 4, 5 and 6 are each learned the same way: alone at 50%, 75%, 100%, then a play-through from measure 1 | | | |
| 30 | Measures 1–6 | 100% | Measure 2 Problem, measure 4 Shaky, measure 5 Problem, the rest Clean | Failed with Problem measures. Repair two blocks: 2 and 5 (rules 9, 11) |
| 31 | Measure 2 | 50% | All notes right, on tempo | Passed. Played alone because measure 1 was Clean (rule 13). Go to song tempo (rule 14) |
| 32 | Measure 2 | 100% | All notes right, on tempo | Passed. Block 2 is fixed; move to block 5 (rules 12, 14) |
| 33 | Measures 3–5 | 50% | One wrong note in measure 4, measure 5 Clean | Passed. Measures 3–4 are the lead-in because measure 4 was Shaky, and lead-ins are not judged (rules 13, 15) |
| 34 | Measures 3–5 | 100% | Two wrong notes in measure 5 | Failed. Repeat at the same tempo (rule 4) |
| 35 | Measures 3–5 | 100% | Measure 5 Clean, on tempo | Passed. All blocks fixed; play the full range again (rule 17) |
| 36 | Measures 1–6 | 100% | All Clean, on tempo | Passed. Add measure 7 (rules 8, 18) |

Two cases the table doesn't reach:

- **Stuck at a tempo:** if run 34 had failed three times in a row, measures 3–5 would drop back to 50% (rule 5).
- **Never quite clean:** if a play-through fails twice with only Shaky measures, those Shaky measures are repaired as if
  they were Problem blocks (rule 10).

## Numbers that can be tuned

| Setting | Value |
|---|---|
| Tempo ladder | 50%, 75%, 100% |
| Long pause | over 1.5 s |
| Problem measure | 2 or more wrong notes |
| Pass mark | 90% of notes right on the first try |
| On tempo | within 15% of the asked tempo |
| Failed runs before stepping down a tempo | 3 |
| Failed play-throughs before repairing Shaky measures | 2 |
| Lead-in length | up to 2 measures |

## Who applies the rules

Recommended: the lesson code applies this playbook, and the AI coach explains each step to the student
("measure 5 tripped you up, let's take it slowly with the two bars before it") and chooses the help in rule 5.
Every rule is a threshold check, so code applies it the same way every time and the lesson keeps moving if the AI is slow or offline.
